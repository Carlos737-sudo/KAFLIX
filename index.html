O projeto

A KARFLIX é uma plataforma de streaming dedicada a filmes produzidos com inteligência artificial, desenvolvida como Trabalho de Conclusão de Curso (TCC) em Desenvolvimento de Sistemas e Programação. Ela simula a experiência de um serviço comercial, com catálogo dinâmico, página para cada filme, player de vídeo e uma identidade visual própria para cada produção.

Objetivos

  • Aplicar HTML5, CSS3 e JavaScript em um projeto completo, organizado e preparado para crescer.
  • Centralizar os dados dos filmes em uma única base usada por todas as páginas.
  • Explorar a inteligência artificial como ferramenta criativa na produção audiovisual.
  • Entregar uma boa experiência em computadores, tablets e celulares.

Desenvolvimento

HTML5 CSS3 JavaScript Canvas API localStorage Design responsivo
  1. Planejamento e identidade visual cinematográfica
  2. Base de dados centralizada de filmes
  3. Catálogo, pesquisa, filtros e gêneros
  4. Efeitos e animações individuais por filme
  5. Player, Minha Lista e testes

Inteligência artificial nas produções

As imagens e os vídeos das produções foram criados com apoio de ferramentas de inteligência artificial generativa, que transformam ideias e descrições em cenas, personagens e atmosferas. Aqui, a IA é uma ferramenta criativa: a ideia, a curadoria e a montagem final são feitas por pessoas.

Projeto acadêmico, sem fins lucrativos. Nomes, personagens e marcas citados pertencem aos seus respectivos titulares. Conheça os títulos no catálogo.
